## 2. 已確認的缺陷與根因

1. `作業面板` 的 17 個超連結都帶著 `r:id`，指向**外部檔案 `v249.xlsx`**。
   只要有 `r:id`，Excel 就會去開那個外部檔，不管內部的 `location` 寫什麼。
2. 就算把外部關聯拿掉，內部 `location` 用的仍是**舊版短頁籤名，本檔一個都不存在**。

### D-02 驗收漏填日期，顯示「已驗收」但不進新制總量【最高】

根因有兩層，都要修：

**第一層 — 狀態判定只看數量**

```
案件總表 O2 = IF($S2="","",IF($H2="無須備料","－",IF($L2="","未驗收","已驗收")))
```

`$L2` 是未使用量（來自驗收記錄 F 欄），**完全沒有檢查驗收日期**。填了數量就是「已驗收」。

**第二層 — 累計卻用驗收日期篩選**

```
新制退料總量對帳 C4 = SUMIFS(驗收記錄!F:F, 驗收記錄!D:D, A4, 驗收記錄!H:H, ">="&新制起算日)
```

累計未使用量以 **H 欄驗收日期** 為篩選條件。日期空白 → 不符合條件 → 這筆不列入應退。

**結果**：案件顯示「已驗收」，但應退量少算，差異永遠對不平，而且畫面上看不出是哪一筆造成的。

**修正**：
1. `案件總表` O 欄改為同時檢查數量與有效日期：

```
=IF($S2="","",IF($H2="無須備料","－",
  IF($L2="","未驗收",
  IF(NOT(ISNUMBER(INDEX('驗收記錄（未使用／返修）'!$H:$H,MATCH($S2,'驗收記錄（未使用／返修）'!$I:$I,0)))),"⚠缺驗收日期","已驗收"))))
```

2. `驗收記錄` H 欄加上日期資料驗證（目前該欄**完全沒有驗證**，只有 F 欄有非負整數限制）。
3. 異常總覽新增一列：驗收已填數量但缺有效日期的筆數。

### D-03 K 欄（關聯單號）仍在決定工班差異列不列入【最高】

`工班退料差異` A4 是整頁的工班清單來源，其中第三段（來自退料批次）是：

```
c = FILTER( 退料批次 L欄(工班)、B欄(品項),
      (L<>"") * (LEFT(L,1)<>"⚠") * (B<>"")
      * ( XLOOKUP(退料批次 K欄關聯單號 → 案件總表 U欄) = "新制案件" ) )
```

**K 欄空白時 XLOOKUP 找不到，該工班就不會出現在清單裡。**
而實退金額欄 F4／G4 只看「工班＋品項＋歸屬＝新制退料」，根本不看 K 欄。

也就是說：判斷「要不要列出這一列」用 K，計算「這一列多少」用 M。兩者不一致，
K 空白且該工班在應退側沒出現過時，整列消失 — 這正是你測到的漏列，
也與「K 欄選填」的定案直接衝突。

**修正**：c 段的新制判定改用歸屬欄，與 F4／G4 一致：

```
c = FILTER( 退料批次 L欄、B欄,
      (L<>"") * (LEFT(L,1)<>"⚠") * (B<>"") * (退料批次 M欄 = "新制退料") )
```

K 欄從此完全不影響列入與否，只留給 N 欄做追溯核對。

### D-04 月租例行拆回（無派工）無法納入工班對帳【高】

```
月租返修品登記 K2 = IF($I2="月租例行拆回（無派工）","無派工", ...)
```

工班欄被填成文字「無派工」。而 `工班退料差異` A4 的 b 段還要求：

```
XLOOKUP(月租 F欄關聯單號 → 案件總表 U欄) = "新制案件"
```

無派工沒有關聯單號 → 查不到 → **整列被排除在工班差異之外**。
但 `總量對帳` D4 是用「品項＋登記日 ≥ 起算日」加總，**會計入總量**。

這就是你測到的「會進整體總量，但沒有歸屬工班」。

**修正**：
1. `月租返修品登記` 新增 L 欄「歸屬工班（無派工必填）」，下拉來源同退料批次 L 欄。
2. K 欄改為：無派工時取 L 欄，L 欄空白時顯示 `⚠缺歸屬工班`。
3. A4 的 b 段新制判定改用「登記日 A ≥ 新制起算日」，與總量對帳 D4 一致，不再依賴關聯單號。
4. 異常總覽新增一列：無派工拆回缺歸屬工班的筆數。

### D-05 關聯單號填錯沒有每日異常【中】

異常總覽第 22 列只計算「本次派工拆回**缺**關聯單號」。
若單號**填錯**，`月租 K2` 會顯示 `⚠查無單號` 或 `⚠工班待確認`，但異常總覽沒有任何一列在數這個值。

**修正**：異常總覽新增一列，計算 `月租返修品登記` K 欄以 `⚠` 開頭的筆數。

---

### D-06 月結「確認結果」與「ERP 修正日」沒有任何限制【高】

`新竹物流月結與金額確認` 整張表**沒有任何資料驗證**。
處理狀態公式只判斷「有沒有填」：

```
V2 = ... IF($H2="","待確認", ... IF($I2="","待填ERP金額修正日","可交財務"))
```

H 欄隨便打一個字就算「已確認」，I 欄隨便打一個字就算「已填修正日」，
接著就會被判定為「可交財務」。

**修正**：
1. H 欄加下拉（選項待確認，見第 4 節）。
2. I 欄加日期驗證。
3. V 欄公式改為只認可下拉中的「相符」值，其餘一律停在待確認或不符狀態。

## 3. 測試沒抓到、但同樣會擋住試行的問題

### D-07 品項下拉參照到不存在的頁籤【最高】

```
月租返修品登記 C2:C2000  資料驗證來源 = 品項主檔!$A$2:$A$201
工班退料批次登記 B2:B2000 資料驗證來源 = 品項主檔!$A$2:$A$201
```

本檔沒有名為 `品項主檔` 的頁籤（實際名稱是 `品項主檔（維護）`），也沒有這個定義名稱。
**兩個品項下拉都是壞的。**

品項是所有對帳的 key，下拉失效就會有人手打，直接製造「未建檔品項」與對不平的差異。
這一項的影響比首頁連結更大，建議排在第一順位一起修。

**修正**：兩處來源改為 `'品項主檔（維護）'!$A$2:$A$201`。

---

### D-08 工班差異與總量對帳的「新制」基準不一致【高】

| 頁面 | 判斷「新制」的依據 |
| --- | --- |
| `工班退料差異` C4（應退-未使用） | 案件總表 U 欄 → **領料日** ≥ 起算日 |
| `新制退料總量對帳` C4（累計未使用） | 驗收記錄 **H 欄驗收日期** ≥ 起算日 |
| `工班退料差異` D4（應退-月租） | 案件總表 U 欄 → **領料日** |
| `新制退料總量對帳` D4（累計月租） | 月租 **A 欄登記日** ≥ 起算日 |

即使所有欄位都填齊，只要**領料日在起算日之前、驗收日在之後**（或相反），
兩頁的應退量就會不一樣，而兩頁都宣稱「差異必須為 0」。

**修正**：兩頁統一基準。建議一律以案件總表 U 欄（領料日）為準，
總量對帳 C4／D4 改為與工班差異相同的判定，理由是退料責任跟著領料走，
而驗收日與登記日是可以補填的。

---

### D-09 一般案件收費下拉不擋清單外輸入【低】

`一般案件收費確認` H 欄的下拉設定為不顯示錯誤訊息，可以直接打字繞過。
I 欄（確認金額）則完全沒有驗證。
影響有限 — L 欄公式會用 `$I2=$G2` 比對，填文字會落到「⚠ERP金額不符」而不會誤放行 —
但仍建議 H 欄改為強制、I 欄加非負數值驗證。

## 5. 動工前需要確認的三件事

1. **驗收缺日期時，案件總表要顯示什麼？**
   建議顯示 `⚠缺驗收日期`（不算已驗收），這樣工程師在案件總表就看得到要補什麼。
   另一種做法是仍顯示「已驗收」但另列異常 — 但這會讓「已驗收卻不進總量」的狀況繼續存在。
2. **月結「確認結果」的下拉選項要用哪些字？**
   建議 `相符` / `不相符`，V 欄只認「相符」才可往下走。
3. **新制基準統一成哪一個？**
   建議一律以領料日（案件總表 U 欄）為準。

## 6. 核心原則（不變）

車號與單號只供追溯；正式核對以**工班＋品項總量**為準。
上述所有修正都不改變這個原則 — D-03 與 D-04 反而是讓它真正成立：
K 欄不再影響列入，無派工拆回也能歸到工班。
